# Predictive-Analytics-Time-Series-R

## ARIMA, SARIMA & Classical Decomposition

* Developed predictive models in R (forecast, tseries, astsa) for economic, meteorological, and healthcare time series data
* Evaluated series stationarity using ACF/PACF diagnostics and Augmented Dickey-Fuller (ADF) tests
* Applied simple and seasonal differencing to transform non-stationary data into stationary series
* Built and tuned ARIMA and SARIMA models, optimizing parameter selection via AIC and BIC criteria
* Conducted rigorous residual analysis using the Ljung-Box test to validate model adequacy and ensure white-noise residuals
* Implemented classical multiplicative decomposition using centered moving averages to isolate trend, seasonality, and cyclical components
* Engineered second-order autoregressive (AR(2)) models via Ordinary Least Squares (OLS) for short-term forecasting
* Generated multi-step future predictions with 80% and 95% confidence intervals to quantify forecast uncertainty
